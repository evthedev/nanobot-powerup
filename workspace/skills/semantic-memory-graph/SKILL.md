# Skill: Semantic Memory Graph

## Purpose
Upgrade `cross-chat-memory` (keyword search) to an associative memory system.

## Overlap Merge
- **Existing:** `cross-chat-memory` (keyword search) and `MEMORY.md` (flat list).
- **New Capability:** Links entities across domains (e.g., "Tank 300" -> "Off-grid" -> "Solar" -> "EV").

## Instructions
1. When a new major topic is researched, identify "Adjacent Interests" in `MEMORY.md`.
2. Use `edit_file` to create a `## Graph` section in `MEMORY.md` using `[[WikiLinks]]` style connections.
3. Before starting any research, query the graph to see how it relates to previous user goals.
